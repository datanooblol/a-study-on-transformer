Study Curriculum

A Study on Transformer

Understanding transformer architecture inside out — not as a language model, but as a general sequence-processing pattern applied to insurance customer data. Nine lessons, each grounded in the actual code in this repo, ending in two examples of the pattern applied outside insurance/NLP entirely.

How to use this

Read the lessons in order the first time — each one builds on the last. After that, use the pill nav above to jump straight to whatever you're rusty on. Every lesson has a Files to open box pointing at the real source in this repo — the code shown is copied verbatim, so you can read the lesson side-by-side with the file in your editor.

Callouts you'll see throughout:

💡 Tip

A detail worth remembering — not a mistake, just something easy to miss.

⚠ Inconsistency / best practice

Somewhere the actual code in this repo is inconsistent, incomplete, or diverges from what you'd do in production. These are called out on purpose instead of smoothed over — they're some of the best learning material here.

✓ Pattern worth reusing

A design choice in this repo that generalizes well and is worth carrying into other projects.
